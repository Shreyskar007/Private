# **App Name**: FriendScore

## Core Features:

- Friend Score Tracking: Track each friend's score, updating in real-time with a +1 button. Scores are persisted locally in a JSON file.
- Score Visualization: Display each friend’s score over time using a line graph, built with recharts.
- Data Persistence: Read and write friend data from a JSON file to persist scores and friend information.
- Initial Data Load: Load all friends and their scores from the JSON file upon app start.

## Style Guidelines:

- Background color: Black (#000000) to provide a sleek and modern backdrop.
- Friend 1 Color: Dark Blue (#1A202C) for the first friend's card.
- Friend 2 Color: Grey (#2D3748) for the second friend's card.
- Friend 3 Color: Purple (#4C3750) for the third friend's card.
- Body and headline font: 'Roboto' (sans-serif) for a modern, clean, and easily readable interface.
- Utilize a responsive grid layout with centered cards and subtle shadows for a clean, minimalist design suitable for both desktop and mobile.
- Use simple, outlined icons in a light color for the +1 button, maintaining a minimalist aesthetic and high contrast.
- Implement subtle animations when scores are updated, providing smooth transitions and user feedback.
